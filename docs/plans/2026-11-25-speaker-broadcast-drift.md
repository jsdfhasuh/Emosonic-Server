# 群播音箱持续进度校正

两首曲目的在线对时采样分别显示音箱比群播目标慢约 94 ms 和 49 ms。现有逻辑在播放中忽略 200 ms 以内的位置差。

在同一队列位置、同一曲目、同一用户倍率的连续进度事件上，按 mpv 的实际位置采样时刻计算带方向的偏差。对于可重复的小偏差，短暂调整速度，随后立即恢复用户倍率并核对实际状态，再发送本条回执。大幅跳转仍走原有定位。暂停、终止、换曲与断线须能随时取代校正。

测试覆盖两组现场偏差、时钟和采样延迟、正反两个方向与抖动、恢复准确倍率、随后不再收到进度、终止抢占和曲目切换。使用可控时钟与独立播放器夹具；设备端声差需要另外采样。

22:14 自然换曲时，旧曲进度与暂停目标分别是 201000 ms、201109 ms，旧曲实长约 201147 ms。音箱再次请求旧曲，随后断线。隔离 mpv 已复现，重新装载一首仅余 3 ms 的曲目可能在初始定位中自然结束，内层 load 异常处理会关闭仍健康的进程。

保留 mpv 确认自然结束的运行标识，使该队列位置随后收到的进度和暂停如实失败，避免重复装载旧曲。显式重播、跳转和另一个队列位置可重新装载。初始定位期间的自然结束沿用现有 EOF 分类，其他控制、媒体与 IPC 错误继续执行原有处置。通过同一 mpv 上的下一首、曲尾初始定位和真实错误对照验证。

14 次隔离 mpv 复演还发现一次顺序差异，定位已经成功，曲尾进度属性先失效，而旧运行的 EOF 在下一次 IPC 往返后才到。对已成功提交、目标在已知曲尾定位容差内的这类错误，最多等 100 ms 接收该运行的 EOF。保留播放事件的正常消费通道；缺少相符 EOF 的故障仍按原路径处理。
