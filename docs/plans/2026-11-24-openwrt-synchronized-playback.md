# OpenWrt 跟随、群播和播放交接

当前音箱只实现普通 Core。为它接入既有 Emo Socket 的同步播放与双向 Handoff，使 Windows 和音箱能在同一时间线上播放，也能把正在播放的歌曲交给对端。

- 复用播放器连接、音频引擎和设备身份。为时钟校准、预加载、按服务端时间执行和播放事实回报补齐共用逻辑。
- Follow 使用服务端租约和源端播放事实驱动跟随端，退出或断线时清理；Broadcast 按源、参与端和控制端的角色处理同步、反馈和恢复。
- Handoff 目标预加载后按时开始，以真实播放状态回报完成；源端等有效释放后停止。取消、迟到和换代后的消息不得误播。
- 先对隔离服务与 mpv 运行正向、取消和恢复测试，再依据实测结果发布能力。家里联测前留存原镜像和播放快照，分别核对 Windows 与 OpenWrt 状态、歌曲、位置和声卡运行状态。
