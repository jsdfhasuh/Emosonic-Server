# 个人听歌主页

- 在网页个人资料页优先展示账号头像、可切换的近 7 天、近 30 天和全部历史统计、代表歌曲与解读。账号、外部服务和串流设置保留原入口与表单，移到页面下方。
- 用服务端播放记录计算次数和歌曲排行。AI 标签覆盖率单独统计，语言比例以带语言标签的播放为分母。页面读取缓存分析，数据显示与换模型分开处理。
- 画像使用独立的 OpenAI 模型配置。对比 GPT-6.2 Sol 与当前 Luna 时使用同一份合成事实；复用现有预算、刷新间隔和失败后保留有效分析的逻辑。
- 主页提供基于用户名字的默认头像和本人上传、删除入口。上传只接受有体积和像素限制的静态图片，统一重编码，使用项目已有的浏览器登录和服务端存储。用户资料和头像均遵循现有用户访问权限，修改仅作用于登录账号并验证表单令牌。
- 验证数据窗口、空数据、非本人访问、上传和重置、旧账号设置及画像模型选择。用隔离数据库做桌面和窄屏预览。线上改动须按该服务的运行管理授权执行。
