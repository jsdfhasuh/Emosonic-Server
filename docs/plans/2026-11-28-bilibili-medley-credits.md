# B 站串烧的歌曲和艺人归属

一个观看条目可以包含多首明确署名的作品。现行结构只允许每个视频产生一条结果，导致舞台串烧丢失歌曲，也混淆舞台表演者和原曲艺人。

- 允许一个视频提供多个有标题证据的歌曲线索。分别记录舞台表演者和明确署名的原曲艺人，对未知归属留空；原有单录音路径继续校验版本。
- 根据明确归属查询国区正式发行，保留目录和曲库校验。舞台本身的录音与原曲分开；并列或歧义的发行不冒充唯一结果。
- 对 B 站提取单独使用 Sol 高思考等级。按标题列出的作品数展开，输出遇到容量上限时拆批或扩容重试。
- 为 CL 建立国区歌手订阅。以 14 天内至少两段不同视频有明确表演者证据触发自动订阅，串烧和重复抓取每个视频只计一次。Oracle 国区艺人身份必须唯一，新订阅按原有待确认策略处理新发行。
- 用 CL 演出 2NE1 的两首歌覆盖来源关联、重复项、错误署名、普通视频和派单边界。使用原 14 天快照隔离预演，检查实际提取和国区结果。
