# 恢复管理员网页并验收 OpenWrt 播放控制

线上管理员页面在查询扫描进度时返回 504；守护进程日志显示 RPC 监听线程已因连接异常退出。默认控制台使用旧协议，能够看到 strict-v2 音箱，但实际点播未通过。用户要求通过日常网页验证真实播放链路。

修复守护进程对单次 RPC 连接异常的处理，并限制管理员网页等待后台扫描状态的时间。核对线上现有网页协议选择、曲库选曲到远程音箱的途径和已有设备行为，使正常控制台入口能够操作当前音箱的真实播放队列。

对异常处理和网页入口运行回归测试，保留当前线上镜像与配置作为回滚依据。在真实已登录的网页点播，通过 SSH CLI 暂停和切歌，对比浏览器曲目、顺序和控制版本、mpv 状态与 AB13X 工作状态。用正常的管理员请求验证控制台及搜索可访问。
