# 国区专辑发现使用 Sol 和长上下文

让专辑发现独立使用 Sol，以百万 token 窗口容纳有依据的听歌历史、专辑信息和候选来源。按实际数据量组装请求，遵循共享费用账本、每个上海日一次排序和发行核验。历史记录缺失时保留未知状态。

- 独立选择发现模型并按实际模型保存缓存、计费。将上下文限制施加在输入与预留输出总量，保留其他工作负载的边界。
- 用去重的不同歌曲数、复听天数、收藏、近期与较长时段趋势，以及候选发行的范围和日推曝光来帮助排序。保留可核实的国区目录依据和负反馈过滤。
- 测试长短输入、跨计价阈值、费用不足、历史上下文和旧缓存。用 Sol 做一轮真实隔离预演，再更新 OpenWrt 并回读配置、任务与订单。无需双模型对比。
