# Home Assistant 音箱控制与本地播报

可选的 `ha_socket` 位于单独挂载的私有目录，现有 CLI 和 mpv IPC 仍在播放器自己的运行目录。HA 通过该 socket 使用播放器的控制、状态和本地 WAV 播报；只接受播放器 UID 或 root。

播报文件来自 socket 旁的 `audio/` 子目录。按文件名打开普通 WAV，防止符号链接或路径逃逸，以同一个已配置音频输出播放。保存当前歌曲和 mpv 实际进度，播报结束或失败后恢复原播放或暂停状态。播报使用独立的运行标识，其结束事件不会推进音乐队列。断线、权威变更和新控制指令优先。

重点测试私有 socket 权限、文件名/文件类型、空闲与暂停、实际位置恢复、播放失败、播报期间暂停或切歌以及迟到的结束事件。硬件上分别检查真实出声、队列和控制执行版本、离家暂停，以及 HA 容器可访问的挂载范围。
