# 客户端音乐头像和听歌主页

Android 和 Windows 通过当前账号已有的 Subsonic 登录读取与网页相同的头像；在发现页和设置中可打开原生个人主页，查看近期播放次数、听过的曲目、最常听的歌和已有的画像分析。未设置头像显示首字，账号切换立即隔离旧图。服务端继续负责每天生成，客户端在前台复查版本，回到应用时重新检查。

服务端提供已认证的头像读取与当前账号的画像摘要，直接使用已有文件、播放聚合和缓存分析。客户端复用账号请求、服务器线路、条件请求和主题，不触发绘图或模型推理。用临时账号覆盖鉴权、无头像、更新、条件响应、账号切换和列表为空等情况，再核对已部署接口。Android 和 Windows 安装验证按项目现有流程进行。
